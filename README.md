# VPN для своих — сервер 3x-ui + Telegram-бот

Человек нажимает «Старт» в [@vpn_for_my_friends_bot](https://t.me/vpn_for_my_friends_bot) и получает пробный день, ссылку-подписку и QR-код. Дальше он платит Telegram Stars (или криптовалютой через CryptoBot), и подписка продлевается сама. Своим людям из белого списка доступ бесплатный.

Секретов в этом репозитории нет. Пароли и токены лежат только на сервере, в `/opt/vpn/.env`.

---

## 1. Что где лежит

**Сервер:** VDSina, Амстердам, Ubuntu 24.04, `89.124.107.46`.
Вход: `ssh -i ~/.ssh/id_rsa root@89.124.107.46`. Пускает только по ключу, вход по паролю выключен.

| Где на сервере | Что это |
|---|---|
| `/opt/vpn/docker-compose.yml` | Описание контейнеров: `3xui` (VPN-панель), `vpn-bot` (бот), `vpn-web` (сайт-маскировка) |
| `/opt/vpn/web/` | Настройки и страница сайта-маскировки (nginx) |
| `/opt/vpn/.env` | **Все секреты**: токен бота, доступ к панели, пароль бэкапов. Права 600 |
| `/opt/vpn/config/settings.yml` | **Цены, тарифы, пробный период, лимиты, рефералы, ссылки на приложения** |
| `/opt/vpn/config/texts.yml` | **Все тексты бота** |
| `/opt/vpn/bot/` | Код бота (копия папки `bot/` из этого репозитория) |
| `/opt/vpn/bot-data/bot.db` | База бота (SQLite): пользователи, подписки, белый список, оплаты, журнал |
| `/opt/vpn/xui/db/x-ui.db` | База 3x-ui: клиенты, подключение, ключи Reality |
| `/opt/vpn/xui/cert/` | HTTPS-сертификат для ссылок-подписок (Let's Encrypt, продлевается сам) |
| `/opt/vpn/backups/` | Зашифрованные бэкапы за 14 дней |
| `/opt/vpn/scripts/` | `backup.sh`, `restore.sh`, `vpn` |

В этом репозитории:
- `bot/` — код бота (Python, aiogram 3, SQLite);
- `deploy/` — `docker-compose.yml`, настройки и тексты (`config/`), скрипты (`scripts/`), пример `.env`.

**Как устроен VPN:**
- Подключение VLESS + Reality + Vision на порту **443**. Маскировка — под собственный сайт сервера `89-124-107-46.sslip.io`: контейнер `vpn-web` (nginx) с настоящим сертификатом слушает `127.0.0.1:8443`. Чужие сайты (`www.samsung.com` и т.п.) не годятся: провайдеры в РФ (проверено на МГТС, 02.10.2026) рвут соединение, когда видят имя большого сайта на IP хостинга.
- Ссылки-подписки отдаются по HTTPS на порту **2096**, адрес `https://89-124-107-46.sslip.io:2096/…`. Это бесплатное имя, которое само указывает на IP сервера, поэтому покупать домен не понадобилось.
- Ссылка у человека одна навсегда. Продления, отключения и смена настроек приходят в приложение сами.

**Открытые порты:**
- 22 — вход на сервер;
- 443 — VPN «🇳🇱 Нидерланды» (TCP + Reality + Vision, отпечаток firefox — chrome фильтр МГТС глушит);
- 2096 — подписки;
- 80 — открывается автоматически только на минуту, когда продлевается сертификат.

Панель 3x-ui снаружи **не видна** (см. раздел 6).

## 2. Команда `vpn` на сервере

```bash
ssh -i ~/.ssh/id_rsa root@89.124.107.46
```

| Команда | Что делает |
|---|---|
| `vpn status` | Работают ли контейнеры, порты, Xray, нагрузка, последний бэкап |
| `vpn logs` / `vpn logs xui` | Живые логи бота / 3x-ui (выход — Ctrl+C) |
| `vpn errors` | Последние ошибки бота |
| `vpn restart` / `vpn restart bot` | Перезапустить всё / только бота |
| `vpn backup` | Сделать бэкап сейчас и прислать в Telegram |
| `vpn restore ФАЙЛ` | Восстановить из бэкапа |
| `vpn update-bot` | Пересобрать и перезапустить бота после изменения кода |
| `vpn update-xui v3.9.0` | Обновить 3x-ui до указанной версии (перед этим сам делает бэкап) |
| `vpn panel` | Подсказка, как открыть панель 3x-ui |

## 3. Бот: что умеет

**Для людей:**
- «Старт» → кнопка «Попробовать бесплатно» → сообщение с QR-кодом, ссылкой и кнопками «🔌 Подключить» и «iPhone / Android / Windows / Mac».
- «🔌 Подключить» открывает страницу подписки с кнопками «Добавить в Happ / v2RayTun / Hiddify / Streisand / v2rayNG / V2Box».
- Пробный период даётся один раз на один Telegram-аккаунт и через сутки выключается сам.
- Напоминания «осталось N часов» с кнопкой «Продлить»: для платных за 24 ч и за 3 ч, для пробных за 3 ч.
- «👤 Мой профиль»: до какого числа, тип доступа, лимит устройств, сколько трафика ушло, когда было последнее подключение, ссылка (нажал — скопировал), QR-код.
- Тарифы с оплатой звёздами или криптовалютой. Новый срок добавляется к оставшемуся, ссылка не меняется.
- «🎁 Пригласить друга»: друг получает 3 дня пробного вместо 1, пригласивший — +7 дней после **первой оплаты** друга. Так нельзя накрутить дни фейковыми аккаунтами.
- «🎟 Промокод»: либо +N дней, либо скидка N% на следующую оплату.
- «💬 Поддержка»: сообщение приходит админам, ответ возвращается человеку в бот.

**Для админа** (`/admin`, видно только ID из `ADMIN_IDS`):
- **📊 Статистика:** пользователи (всего, за сегодня, за месяц), активные подписки (платные, пробные, бесплатные), кто онлайн, выручка за день, месяц и всё время.
- **🔎 Пользователь:** по ID, @username или пересланному сообщению. Можно начислить +1/+7/+30/+N дней, внести в белый список, забанить или разбанить, написать человеку.
- **💚 Белый список, ➕ Добавить своего, 🔗 Ссылка без Telegram** — см. раздел 4.
- **📣 Рассылка:** присылаете сообщение (текст, фото, видео), бот показывает предпросмотр, после подтверждения рассылает и присылает отчёт.
- **🎟 Промокоды:** создать или удалить.
- **🖥 Сервер:** Xray, процессор, память, диск, кто онлайн.
- **📜 Журнал:** все действия админов (белый список, бан, начисления, рассылки, возвраты).
- Команды:
  - `/user ID` — карточка пользователя;
  - `/refund ID` — вернуть звёзды;
  - `/testmode` — тестовые цены;
  - `/reload` — перечитать настройки.

**Уведомления админу:**
- новый пользователь;
- выдан пробный период;
- оплата;
- человек из белого списка нажал «Старт»;
- закончился бесплатный доступ;
- обращение в поддержку;
- **сбой** (3x-ui не отвечает или Xray остановлен больше 3 минут) и **восстановление**;
- диск заполнен больше чем на 90%;
- «бот запущен» — после перезагрузки или обновления.

## 4. Белый список (бесплатно для своих)

**Добавить:** `/admin` → «➕ Добавить своего». Указать человека можно любым способом:
- кнопкой «👤 Выбрать контакт»;
- переслать любое его сообщение;
- прислать `@username` или числовой ID.

Дальше бот спросит:
1. Заметку «кто это».
2. Срок: бессрочно, месяц, 3 месяца, год или своя дата.
3. Лимит устройств (по умолчанию без лимита).
4. Лимит трафика (по умолчанию без лимита).

- Если человек уже в боте, ему сразу придёт ссылка.
- Если ещё нет, запись ждёт. При первом «Старт» он сразу получит бесплатный доступ без пробного периода и тарифов, а вам придёт уведомление.
- Человек из белого списка не видит тарифов и напоминаний об оплате. В профиле у него написано «Доступ бесплатный».

**Список:** «💚 Белый список». Для каждого видно:
- кто это и когда добавлен;
- сколько трафика потратил;
- когда последний раз подключался.

В карточке есть кнопки:
- ссылка и QR-код;
- ✏️ срок, устройства, трафик, заметка;
- 🗑 «Убрать из списка» — бот спросит, что сделать:
  - **⛔️ Отключить сразу** — VPN перестаёт работать, человеку ничего не пишем;
  - **💳 На обычные условия** — у человека остаётся 3 дня (`unwhitelist_grace_days`), бот предлагает оплатить, ссылка та же.

**Без Telegram:** «🔗 Ссылка без Telegram» → заметка, срок, лимиты → бот пришлёт ссылку и QR-код, их можно отправить человеку как угодно. Человек ставит Happ, нажимает «+» → «Добавить из буфера».

Все изменения пишутся в журнал (`📜 Журнал`). Менять белый список может только админ.

**Сейчас в списке:**
- `worker (сервер)` — без Telegram, бессрочно, ссылка выдана для рабочего сервера.
- `402982907` — Александр. Бессрочно, ссылка уже выдана.

## 5. Как поменять цены, тексты, лимиты

1. На сервере: `nano /opt/vpn/config/settings.yml` (цены и тарифы) или `nano /opt/vpn/config/texts.yml` (тексты).
2. Сохранить: Ctrl+O, Enter, Ctrl+X.
3. В боте отправить `/reload`. Если в файле ошибка, бот скажет, где, и продолжит работать со старыми настройками.

Чтобы изменения не потерялись при следующей выкладке, поправьте те же файлы и в репозитории, в `deploy/config/`.

Что настраивается в `settings.yml`:
- `plans`: название, дни, цена в звёздах (`stars`) и в рублях для криптовалюты (`rub`), бейдж «−10%». `code` у существующих тарифов не менять.
- `trial.hours`: длительность пробного периода.
- `device_limit`, `traffic_limit_gb`: лимиты обычной подписки.
- `reminders`: за сколько часов напоминать.
- `referral`: бонусы за приглашения.
- `apps`: ссылки на приложения в инструкциях.

**Как работает лимит устройств.** Если с подписки одновременно подключено больше `device_limit + 1` разных IP-адресов, лишние на время блокируются. Запас +1 нужен потому, что телефон при переключении Wi-Fi и мобильной сети ненадолго виден с двух адресов. Лимит по «ID устройства» (HWID) специально не используется: он ломает v2rayNG, Streisand и V2Box, они этот ID не передают.

## 6. Панель 3x-ui

Панель слушает только `127.0.0.1`, из интернета её не видно. Открывается через SSH-туннель:
1. На сервере выполните `vpn panel`, она покажет точную команду.
2. На Mac выполните эту команду. Она выглядит так:
   ```bash
   ssh -i ~/.ssh/id_rsa -N -L 8443:127.0.0.1:ПОРТ root@89.124.107.46
   ```
3. В браузере откройте `http://127.0.0.1:8443/ПУТЬ/`.
4. Логин и пароль лежат в `/opt/vpn/.env` (`XUI_USERNAME`, `XUI_PASSWORD`).

Клиентов руками в панели лучше не создавать и не править: бот считает свою базу главной и при продлении перезапишет изменения. Выдавайте доступ через бота.

## 8. Оплата

**Telegram Stars** — включены. По правилам Telegram цифровые услуги внутри бота продаются за звёзды.
- Деньги приходят на баланс бота: @BotFather → бот → Payments, или в самом Telegram «Мои звёзды».
- Вывод через [Fragment](https://fragment.com) в криптовалюту TON. Минимум 1000 ⭐, звёзды становятся доступны к выводу через 21 день. За 1 звезду вы получаете примерно $0,013.

**Проверить полный цикл оплаты (делает Александр, это ~1 ⭐):**
1. В боте: `/admin` → «💚 Белый список» → «Александр» → «🗑 Убрать» → «💳 На обычные условия». Так вы станете обычным пользователем с 3 днями доступа.
2. Отправьте `/testmode`: для админов все тарифы станут стоить 1 ⭐.
3. Главное меню → «💳 Продлить» → «1 месяц» → «⭐ Telegram Stars» → оплатите 1 ⭐.
4. Проверьте:
   - пришло «Оплата прошла», подписка продлена на 30 дней;
   - пришло уведомление админу «💰 Оплата (ТЕСТ)»;
   - ссылка в профиле не изменилась.
5. Верните звезду: `/refund` (покажет список оплат) → `/refund НОМЕР`.
6. Снова отправьте `/testmode` — режим выключится.
7. Верните себя в белый список: `/user 402982907` → «💚 В белый список».

**CryptoBot (USDT/TON)** — код готов. Чтобы включить:
1. Откройте [@CryptoTestnetBot](https://t.me/CryptoTestnetBot) для теста или [@CryptoBot](https://t.me/CryptoBot) для боевого режима.
2. Crypto Pay → Create App → скопируйте токен.
3. На сервере в `/opt/vpn/.env` впишите `CRYPTOPAY_TOKEN=токен`. Для теста `CRYPTOPAY_TESTNET=true`, для боевого `false`.
4. Выполните `vpn restart bot`.

В тарифах появится кнопка «💎 Криптовалюта». Счёт выставляется в рублях, человек платит USDT или TON по курсу, бот сам проверяет оплату раз в 20 секунд.

ЮKassa и Robokassa не подключены. Им нужен статус самозанятого или ИП, VPN-магазины у них, по отзывам, блокируют, и это нарушает правило Telegram про звёзды.

## 9. Бэкапы и восстановление

**Каждую ночь в 03:30 по Москве** (`/etc/cron.d/vpn-backup`) скрипт делает бэкап:
- база 3x-ui и база бота (с проверкой целостности);
- `.env`, настройки и сертификат.

Архив шифруется паролем `BACKUP_PASSPHRASE` из `.env`, хранится 14 дней в `/opt/vpn/backups/` и **приходит админам в Telegram**. Лог: `/var/log/vpn-backup.log`.

> ⚠️ Пароль бэкапов сохраните у себя, например в менеджере паролей. Без него архив из Telegram не открыть.
> Посмотреть пароль: `grep BACKUP_PASSPHRASE /opt/vpn/.env`.

**Восстановить на этом же сервере** (проверено 02.10.2026):
```bash
vpn restore /opt/vpn/backups/vpn-2026-10-02_0330.tar.gz.enc
```
Текущие базы перед заменой сохраняются в `/opt/vpn/backups/before-restore-*`.

**Восстановить на новом сервере** (Ubuntu 24.04):
1. Поставьте Docker из официального репозитория (docs.docker.com/engine/install/ubuntu) и `sqlite3`.
2. Скопируйте `deploy/` и `bot/` из репозитория:
   ```bash
   rsync -a deploy/ root@НОВЫЙ_IP:/opt/vpn/
   ```
   ```bash
   rsync -a bot/ root@НОВЫЙ_IP:/opt/vpn/bot/
   ```
3. Загрузите архив из Telegram на сервер и запустите `/opt/vpn/scripts/restore.sh ФАЙЛ`. Пароль скрипт спросит сам, `.env` и сертификат возьмёт из архива.
4. Если у сервера другой IP:
   - в 3x-ui (раздел 6) поменяйте адрес в подключении: Inbound → External Proxy;
   - в `.env` поменяйте `SUB_BASE_URL` на `https://НОВЫЙ-IP-ЧЕРЕЗ-ДЕФИСЫ.sslip.io:2096/…`;
   - выпустите сертификат: `certbot certonly --standalone -d НОВЫЙ-IP.sslip.io`.

   Старые ссылки у людей указывают на старый адрес, поэтому при переезде на новый IP люди должны заново нажать «🔌 Подключить».

## 10. Обновления

- **Ubuntu** ставит обновления безопасности сама (`unattended-upgrades`).
- **3x-ui:** посмотрите номер версии на github.com/MHSanaei/3x-ui/releases и выполните `vpn update-xui v3.X.Y`. Если что-то сломалось, верните прежнюю версию (`vpn update-xui v3.8.5`) и при необходимости бэкап. Обновлять 3x-ui стоит не в день выхода новой версии, а через несколько дней.
- **Бот:** поправили код в `bot/` →
  ```bash
  rsync -a --delete --exclude __pycache__ bot/ root@89.124.107.46:/opt/vpn/bot/
  ```
  → на сервере `vpn update-bot`.
- **Сертификат** продлевается сам (`certbot.timer`), после продления 3x-ui перезапускается.

## 11. Если что-то перестало работать

**VPN не подключается ни у кого:**
1. `vpn status`. Оба контейнера должны быть `Up`, а Xray — `running`. Если нет: `vpn restart`, затем `vpn logs xui`.
2. Работает ли сам сервер: зайдите по SSH. Если не пускает — панель VDSina → перезагрузить, посмотреть консоль.
3. Работает ли сайт-маскировка: `docker ps` — контейнер `vpn-web` должен быть `Up`. Если подключение есть, а сайты не грузятся — смотрите на сервере `tcpdump -ni ens3 port 443`: если от телефона приходит только первый пакет и дальше тишина, это фильтр провайдера по имени сайта.
4. Не заблокирован ли IP сервера в России. Признак: из России не подключается никто, при этом из-за границы работает. Лечится сменой IP или сервера.

**VPN не работает у одного человека:**
1. `/user ID` в боте: активна ли подписка, не забанен ли, когда было последнее подключение.
2. Попросите его в приложении нажать «обновить подписку» или заново «🔌 Подключить».
   На iPhone проверено: v2RayTun «подключается», но сайты не грузятся, а Happ с той же подпиской работает. Если v2RayTun не работает — ставьте Happ (TestFlight).
3. Если подключено больше устройств, чем разрешено, лишние IP блокируются на время. Это нормально.

**Бот не отвечает:**
1. `vpn status` → `vpn errors` → `vpn logs`.
2. `vpn restart bot`.
3. Ошибка в `settings.yml` или `texts.yml` после правки видна в `vpn logs`. Исправьте файл и снова `vpn restart bot`.

**Не пришёл ночной бэкап:** `tail /var/log/vpn-backup.log`.

**Не открывается ссылка-подписка:** проверьте сертификат командой `certbot certificates`. Если срок истёк — `certbot renew`.

**Важно про уведомления о сбоях.** Бот живёт на том же сервере, поэтому если упадёт **весь сервер**, написать о сбое будет некому. Для этого стоит завести бесплатный внешний мониторинг, например UptimeRobot: монитор «Port» на `89.124.107.46:443` с уведомлением в Telegram.

## 12. Безопасность

- В SSH пускает только по ключу: вход по паролю выключен, root входит только по ключу. fail2ban банит IP на час после 5 неудачных попыток.
- Файрвол `ufw` открывает только порты 22, 443 и 2096.
- Панель 3x-ui доступна только через SSH-туннель. У неё случайный порт, случайный путь, свой логин и длинный пароль. Бот обращается к ней по API-токену.
- Секреты лежат только в `/opt/vpn/.env` (chmod 600). В git и в Telegram-бэкапах они только в зашифрованном архиве.
- Бот в контейнере работает не от root, память ограничена 256 МБ.

## 13. Второй сервер (на будущее)

3x-ui v3 умеет управлять несколькими серверами («Nodes»). Бот добавляет клиентов во все подключения из `XUI_INBOUND_IDS`. План:
1. Поставить на новом сервере 3x-ui как узел (node).
2. Подключить его к главной панели.
3. Добавить ID его подключения в `XUI_INBOUND_IDS`.

В подписке у людей тогда появятся две локации, а ссылка останется прежней.

## 14. Важно про законы РФ

Пользоваться VPN в России не запрещено. Но **реклама VPN и публикация способов обхода блокировок наказываются штрафами**: с 2024 года запрещено распространять инструкции по обходу блокировок, с сентября 2025 года — рекламировать VPN. Поэтому:
- тексты бота написаны нейтрально («защищённое подключение»);
- продвигайте бота только среди знакомых и без публичной рекламы.

Это не юридическая консультация.
